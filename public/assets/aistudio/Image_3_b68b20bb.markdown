## Brand & Style

This design system embodies a dependable, high-performance developer console aesthetic tailored for technical AI interactions, complex prompt workflows, and code execution. Designed for software engineers, ML researchers, and technical power users, it prioritizes clarity, structural hierarchy, and low cognitive friction during prolonged deep-work sessions.

The visual style combines Corporate Modern restraint with technical minimalism:
- **Calm, High-Information Density:** Utilitarian dark slate surfaces paired with crisp structural demarcation replace heavy decorative ornamentation.
- **Engineered Precision:** Interfaces feel calibrated rather than decorative; interactive states provide immediate, decisive tactile feedback.
- **Atmospheric Focus:** Dark-mode-first workspace design mitigates eye fatigue, using targeted indigo-violet accents and luminous gradients exclusively to signify generation, processing states, and active execution contexts.

## Colors

The color palette centers on a disciplined neutral dark architecture, punctuated by controlled spectral transitions for generative and interactive elements.

### Color Tokens & Roles
- **Canvas Base (`#09090b`):** Deep charcoal-zinc foundational background for root layouts and terminal frames.
- **Surface Elevation 1 (`#18181b`):** Secondary container surface utilized for sidebars, secondary drawers, and card backdrops.
- **Surface Elevation 2 (`#27272a`):** Interactive fields, user input containers, message bubbles, and hover states.
- **Subtle Borders (`#27272a` / `#3f3f46`):** Low-contrast structural lines providing structural containment without visual clutter.
- **Primary Accent (`#6366f1`):** Core interactive state color for primary triggers, active tabs, and focused controls.
